# 나디페(NADIPE) 서비스 기획서
## : AI 기반 디지털 관상 & 멀티 페르소나 탐험 플랫폼

> **세대를 넘는 한 줄 메시지**
> MZ에겐 “내 디지털 부캐를 인스타에 자랑하고 싶은 콘텐츠”,
> X세대에겐 “디지털 시대에 다시 보는 나의 관상(觀相), 그리고 또 다른 나”.
> 같은 서비스, 두 세대에게 각자 다른 의미로 도착한다.

> **폭발적 이슈화의 한 줄**
> “당신은 한 명이 아니다. AI가 당신 안에 숨어 있던 또 다른 나를 꺼낸다.”

---

# 1. 서비스 개요

## 서비스명
나디페 (NADIPE)

= 나의 디지털 페르소나 (My Digital Persona**s**)

복수형이 핵심이다. **나의 페르소나는 하나가 아니다.**

---

## 서비스 한줄 소개

나디페는 사용자의 디지털 흔적을 기반으로
AI가 삶의 리듬, 감정 패턴, 사회적 세계를 해석해주고,
**여러 개의 나(메인캐·부캐·오늘의 나)** 를 발견해
**각 페르소나가 속한 서로 다른 세계** 로 데려가는
신개념 “디지털 관상” 플랫폼이다.

---

# 2. 핵심 컨셉

## “나를 알고, 내가 속한 세계를 알고, 다른 세계의 사람들을 만나는 경험”

사람들은 단순히 연애만 원하는 것이 아니다.

진짜 원하는 것은:

- 나는 어떤 사람인가
- 나는 어떤 세계를 살아가는가
- 다른 사람들은 어떤 세계를 살아가는가
- **나의 또 다른 모습은 어떤 세계에 살고 있는가**

를 알고 싶은 것이다.

---

나디페는 사람을:
- 외모
- 스펙
- 직업

으로 평가하지 않는다.

대신:
- 디지털 흔적
- 삶의 리듬
- 감정 패턴
- 사회적 분위기
- 온라인 세계관
- **순간순간 달라지는 멀티 페르소나**

를 기반으로 AI가 사람의 “디지털 페르소나**들**”을 해석한다.

---

# 2-1. 멀티 페르소나 선언

## “당신은 한 명이 아니다”

당신 안에는 여러 명이 살고 있다.

- 출근하는 나
- 새벽에 깨어있는 나
- 친구들과 있는 나
- 혼자 음악 듣는 나
- 어제의 나, 오늘의 나, 일요일의 나
- 메인캐와 부캐

같은 사람이라도 **어떤 페르소나가 켜져 있느냐**에 따라
듣는 음악, 가는 곳, 만나는 사람, 속한 세계가 전부 달라진다.

---

## 나디페의 페르소나 구조

| 구분 | 정의 | 예시 |
|---|---|---|
| **메인 페르소나 (메인캐)** | 가장 자주 드러나는 나, 사회적 자아 | “책임감 있는 직장인” |
| **서브 페르소나 (부캐)** | 숨겨두거나 가끔 켜는 또 다른 나 | “새벽 감성러”, “덕질러” |
| **데일리 페르소나 (오늘의 나)** | 오늘 하루의 컨디션·감정 리듬 | “오늘은 몰입형”, “오늘은 회복형” |
| **시즈널 페르소나** | 계절·시기에 따른 나 | “여름의 나”, “연말의 나” |
| **섀도우 페르소나 (그림자 자아)** | AI만이 디지털 흔적에서 찾아낸, 본인도 몰랐던 나 | “당신이 의식하지 못한 또 다른 당신” |

> **핵심 메커니즘**
> **어떤 페르소나가 활성화되느냐에 따라**
> → 나의 세계가 다르게 보이고,
> → 내가 속한 세계가 달라지고,
> → 만나게 되는 사람도 달라진다.

> **WORLD MAP과의 연결**
> 위의 각 페르소나는 결국 아래 **NADIPE WORLD MAP의 16개 세계 유형** 중 하나로 분류된다.
> 즉, 한 사람의 메인캐는 “심해형 인간”의 세계에, 부캐는 “밤의 제작자”의 세계에 속할 수 있다.

---

# 3. NADIPE WORLD MAP — 디지털 관상 세계 지도

나디페는 사람의 “성격”보다
사람이 살아가는 **“삶의 리듬과 세계”** 를 분류한다.

페르소나(메인캐/부캐/오늘의 나)가 활성화되면,
AI는 그 페르소나를 아래 **16개 세계 유형 중 하나**로 매핑한다.

---

## 3-1. 세계 구조 — 4개의 축

나디페는 사람을 4개의 축으로 해석한다.

### [에너지]
사람과 연결되는 방식

### [삶의 속도]
세상을 살아가는 템포

### [감정 표현]
감정을 드러내는 방식

### [관계 방식]
사람과 가까워지는 형태

---

## 3-2. NADIPE 16 WORLD TYPES

| 유형 | 키워드 | 특징 |
|---|---|---|
| 새벽 사색가 | 깊은 몰입 / 혼자 회복 | 조용하지만 내면 세계가 깊음 |
| 도시 리더형 | 빠른 흐름 / 책임감 | 사회적 에너지와 추진력이 강함 |
| 감정 관찰자 | 분위기 민감 / 내면형 | 감정을 세밀하게 읽지만 쉽게 지침 |
| 밤의 제작자 | 새벽 집중 / 창작형 | 밤에 살아나는 몰입형 인간 |
| 심해형 인간 | 느린 관계 / 깊은 연결 | 가까워지긴 어렵지만 오래 감 |
| 불꽃 탐험가 | 즉흥 / 경험 중심 | 새로운 자극과 세계를 좋아함 |
| 현실 설계자 | 안정 / 계획형 | 현실감각과 구조를 중요시함 |
| 세계 연결자 | 사람 중심 / 교류형 | 관계 속에서 에너지를 얻음 |
| 고요한 기록자 | 관찰 / 기록형 | 말보다 생각과 기록을 선호 |
| 파동 공감자 | 감정 동기화 | 주변 감정에 쉽게 영향을 받음 |
| 미래 구축자 | 성장 / 실행형 | 미래를 설계하고 밀어붙이는 타입 |
| 느린 여행자 | 여유 / 감성형 | 속도보다 경험과 감정을 중시 |
| 회색 분석가 | 논리 / 거리조절 | 감정보다 구조와 분석 선호 |
| 유리 감성가 | 섬세 / 내면축적 | 쉽게 상처받지만 감정이 깊음 |
| 별빛 낙관가 | 따뜻함 / 희망형 | 사람과 가능성을 믿는 타입 |
| 경계의 방랑자 | 자유 / 독립형 | 한 세계에 오래 머물지 않음 |

## 3-3. NADIPE WORLD MAP (좌표 시각화)

```
                              [사람 중심]
                                   ↑
                                   │
                  세계 연결자        │        도시 리더형
                                   │
        별빛 낙관가                  │                미래 구축자
                                   │
   ────────────────────────────────┼──────────────────────────────→
                                   │
        느린 여행자                  │                불꽃 탐험가
                                   │
                  파동 공감자        │        밤의 제작자
                                   │
                                   ↓
                              [혼자 몰입]

       ← 안정 / 느림                                   변화 / 속도 →
```

> 가로축: **삶의 속도** (안정·느림 ↔ 변화·속도)
> 세로축: **에너지의 방향** (사람 중심 ↔ 혼자 몰입)
> 16개 유형은 이 평면 위 여러 위치에 분포한다 (위 좌표는 8개 대표 유형만 표시).

## 3-4. 각 세계 설명

### 1. 새벽 사색가
- **키워드**: 깊은 생각 / 혼자 회복 / 야행성 감성
- **한줄**: “사람 많은 곳에서도 자기만의 세계를 유지하는 사람”

### 2. 도시 리더형
- **키워드**: 책임감 / 빠른 실행 / 사회적 중심
- **한줄**: “바쁜 도시의 흐름 속에서도 중심을 잡는 사람”

### 3. 감정 관찰자
- **키워드**: 분위기 민감 / 감정 피로 / 조용한 공감
- **한줄**: “말보다 분위기를 먼저 읽는 사람”

### 4. 밤의 제작자
- **키워드**: 새벽 몰입 / 창작 / 깊은 집중
- **한줄**: “세상이 잠든 시간에 가장 선명해지는 사람”

### 5. 심해형 인간
- **키워드**: 느린 관계 / 깊은 신뢰 / 내면형
- **한줄**: “쉽게 가까워지진 않지만 오래 남는 사람”

### 6. 불꽃 탐험가
- **키워드**: 충동성 / 경험 중심 / 자유
- **한줄**: “새로운 세계를 발견할 때 가장 살아나는 사람”

### 7. 현실 설계자
- **키워드**: 계획형 / 안정감 / 구조 선호
- **한줄**: “감정보다 삶의 균형을 먼저 설계하는 사람”

### 8. 세계 연결자
- **키워드**: 관계 중심 / 소통 / 커뮤니티
- **한줄**: “사람과 연결될 때 가장 큰 에너지를 얻는 사람”

### 9. 고요한 기록자
- **키워드**: 기록 / 관찰 / 혼자 생각
- **한줄**: “말보다 기록 속에서 자신을 표현하는 사람”

### 10. 파동 공감자
- **키워드**: 감정 동기화 / 분위기 흡수 / 공감력
- **한줄**: “타인의 감정을 자신의 일처럼 느끼는 사람”

### 11. 미래 구축자
- **키워드**: 성장 / 목표 / 추진력
- **한줄**: “현재보다 미래를 더 오래 바라보는 사람”

### 12. 느린 여행자
- **키워드**: 감성 / 여유 / 경험
- **한줄**: “속도보다 순간의 감정을 더 중요하게 여기는 사람”

### 13. 회색 분석가
- **키워드**: 논리 / 분석 / 거리 유지
- **한줄**: “감정보다 구조를 먼저 이해하려는 사람”

### 14. 유리 감성가
- **키워드**: 섬세함 / 감정 축적 / 내면 깊이
- **한줄**: “조용하지만 감정의 밀도가 높은 사람”

### 15. 별빛 낙관가
- **키워드**: 희망 / 따뜻함 / 긍정 에너지
- **한줄**: “사람과 가능성을 쉽게 포기하지 않는 사람”

### 16. 경계의 방랑자
- **키워드**: 자유 / 독립 / 새로운 세계
- **한줄**: “한곳에 머무르기보다 새로운 세계를 떠도는 사람”

## 3-6. WORLD MAP × 멀티 페르소나

한 사람은 16개 세계 중 **여러 곳**에 동시에 속할 수 있다.

# 4. 서비스 철학

## “디지털 관상”

과거에는:
- 얼굴
- 말투
- 손글씨
- 옷차림

으로 사람을 읽었다면,

이제는:
- 이메일
- 활동 시간
- 음악 취향
- 사용하는 플랫폼
- 디지털 행동 패턴

이 새로운 “관상”이 되는 시대다.

---

## “디지털 관상은 하나가 아니다”

옛 관상학에서도 사람의 얼굴은 시간에 따라 변한다고 했다.
디지털 관상은 더 빠르게 변한다.

- 어제의 디지털 관상
- 오늘의 디지털 관상
- 부캐의 디지털 관상

나디페는 이 **변화 그 자체**를 콘텐츠로 만든다.

> **세대별 해석 포인트**
> - X세대: “관상은 옛날에도 봤지. 그런데 사람이 한 얼굴만 갖고 있는 건 아니지.” — 다면적 인간에 대한 깊은 공감.
> - MZ세대: “MBTI는 16개로 끝났는데, 부캐는 무한이잖아.” — 자기 표현의 무한 확장.

# 5. 핵심 사용자 경험

# 5-0. 페르소나를 켠다

사용자는 앱을 켤 때마다 묻는다.

> **“오늘 당신은 어떤 모드인가요?”**

- 평소의 나 (메인캐)
- 다른 나 (부캐)
- 오늘의 나 (데일리)
- AI가 추천하는 나 (섀도우)

선택한 페르소나에 따라 **앱 전체의 톤, 피드, 만나게 되는 사람, 추천 콘텐츠** 가 바뀐다.

---

# 5-1. 나를 발견한다 — 그리고 또 다른 나를 발견한다

사용자는:
- 이메일
- 관심사
- 활동 시간
- 플랫폼 연결

등을 기반으로 AI에게 **여러 개의** 디지털 페르소나를 분석받는다.

각 페르소나는 **WORLD MAP의 16개 세계 유형 중 하나**로 매핑된다.

---

“혼자만의 몰입 세계를 중요하게 여기는 사람”

“겉으로는 차분하지만 내면에는 강한 호기심이 살아있는 타입”

**[밤의 제작자]**

### AI 한줄평

# 5-2. 내가 속한 세계를 이해한다

나디페는 단순 성격 분석이 아니다.

사용자가:

- 어떤 감정 패턴을 가지는지
- 어떤 사회적 분위기에 익숙한지

를 AI가 해석한다.

**그리고 각 페르소나는 WORLD MAP 위 서로 다른 좌표에 놓인다.**

### 부캐의 세계 — 밤의 제작자

### 오늘의 세계 — 파동 공감자

# 5-3. 다른 세계를 탐험한다

사용자는:
자신과 다른 삶을 사는 사람들의 세계를 탐험한다.

**활성화된 페르소나에 따라 보이는 피드가 완전히 달라진다.**

- 메인캐로 들어가면 → 같은 세계 유형(예: 심해형 인간)의 사람들
- 부캐로 들어가면 → 부캐 세계 유형(예: 밤의 제작자)의 사람들
- 오늘의 나로 들어가면 → 같은 오늘을 사는 사람들

---

## 콘텐츠 예시

- 새벽 2시에 살아있는 사람들 *(밤의 제작자 / 새벽 사색가)*
- 대기업 인간의 외로움 *(도시 리더형 / 회색 분석가)*
- 연구원들이 사랑하는 방식 *(고요한 기록자 / 심해형 인간)*
- 병원이라는 세계에서 살아간다는 것 *(현실 설계자 / 파동 공감자)*
- 스타트업 인간은 왜 답장이 늦을까? *(미래 구축자)*
- 40대가 되어서야 알게 된 직장의 진짜 얼굴 *(X세대 훅)*
- 90년대생이 회사에 적응하는 법 *(MZ 훅)*
- **메인캐는 회사원, 부캐는 시인인 사람들**
- **본업과 부캐의 거리가 가장 먼 사람 TOP 10**

# 5-4. 페르소나가 바뀌면 만나는 사람도 바뀐다

이것이 나디페의 **가장 강력한 차별점**이다.

| 활성 페르소나 | WORLD MAP 매핑 | 추천되는 사람 |
|---|---|---|
| 메인캐 (직장인) | 도시 리더형 / 현실 설계자 | 같은 업계, 비슷한 리듬의 사람 |
| 부캐 (덕질러) | 불꽃 탐험가 / 밤의 제작자 | 같은 취향을 공유하는 부캐러들 |
| 오늘의 나 (회복형) | 감정 관찰자 / 유리 감성가 | 오늘 같은 감정을 가진 사람 |
| 섀도우 (숨은 자아) | 경계의 방랑자 / 새벽 사색가 | AI가 “당신과 닮은 그림자”를 가진 사람 |

> **사용자 인사이트**
> “회사 사람들 사이에선 답답했는데,
> 부캐 모드로 들어오니 처음으로 ‘내 사람들’을 만났다.”

# 15. 장기 비전

나디페는 장기적으로:

> **“AI 시대의 인간 해석 플랫폼”**

이 되는 것을 목표로 한다.

---

사람들은 점점:
- 디지털 흔적 속에 살아가고
- 온라인 정체성이 현실 정체성이 되고
- **한 명이 여러 명으로 살아가는 시대** 를 맞이하고 있다.

---

나디페는 그 디지털 흔적 속에서

> **“당신은 어떤 사람이고, 그리고 또 어떤 사람들인가”**

를 읽어내는 플랫폼이 된다.

---

# 16. 슬로건 후보

기본:
- AI가 읽은 당신의 디지털 관상
- 우리는 모두 다른 세계를 살아간다
- 당신의 디지털 흔적은 어떤 삶을 말하고 있나요?
- 나를 알고, 다른 세계를 만나다
- 당신은 어떤 세계에 속해 있나요?
- 디지털 흔적은 당신을 닮아갑니다

---

## 멀티 페르소나 슬로건 ★ 핵심

- **“당신은 한 명이 아닙니다.”**
- “당신 안의 또 다른 당신을 만나보세요.”
- “메인캐와 부캐, 둘 다 당신입니다.”
- “오늘의 당신은 어떤 모드인가요?”
- “페르소나가 바뀌면, 세계가 바뀐다.”
- “AI는 당신이 몰랐던 당신까지 알고 있습니다.”

---

## WORLD MAP 슬로건

- **“우리는 모두 다른 세계를 살아간다.”**
- “16개의 세계, 무한한 당신.”
- “당신의 좌표는 어디인가요?”

---

## 세대 가교 슬로건

- **MZ향**: “MBTI 다음은, 디지털 부캐.”
- **X세대향**: “관상은 변한다. 그리고 당신도 한 사람이 아니다.”
- **전 세대 공통**: “당신의 하루가, 당신을 말한다. 그리고 당신은 매일 다른 사람입니다.”
